# Minesweeper
A simple Minesweeper clone made with Python and PyGame.
## How to Run
This project requires [Python3](https://www.python.org/) and [PyGame](https://www.pygame.org/)  in order to run.  
Once those dependencies are installed, download the repository and run the following command in the project root directory to run the app:
```
python3 main.py
```
## How to Play
The goal of the game is to reveal every cell without revealing any mines.  
Click on cells to reveal them.  
Numbers on cells indicate how many mines are neighboring them.  
Right click hidden cells to flag them, use this to keep track of where mines are located.
